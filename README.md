# Angelic Charles — Portfolio

A responsive static portfolio for Angelic Charles, built with HTML, CSS and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or start a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deploy with GitHub Pages

1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select `main` and `/(root)`, then save.
4. GitHub Pages will publish the site at the repository's Pages URL.

## Features

- Dark and light themes, with preference saved locally.
- Responsive navigation.
- Lightweight animated neural network on the homepage.
- Reduced-motion support.
- Sections for Research, Engineering, Writing, Other Interests, About and Now.

## Before treating this as a final CV/portfolio

Please review the project statuses, tool lists, education labels and affiliations for accuracy. The neural activity is a lightweight Canvas animation, not a biological simulation. The calendar is intentionally a placeholder until confirmed events are supplied.
